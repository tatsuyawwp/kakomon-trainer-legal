# プライバシーポリシー

**最終更新日: 2026年10月7日**

「過去問トレーナー」（以下、「本アプリ」）は、ユーザーの個人情報の保護を重視し、以下の方針に基づいて取り扱います。

## 1. 収集する情報とその利用目的

本アプリは、ユーザーのプライバシーを尊重し、個人を特定できる情報（氏名、メールアドレス、電話番号等）を収集・保持することはありません。

### (1) 端末内に保存されるデータ
- ユーザーが作成・取り込んだ問題集データ（設問、選択肢、解答）
- 学習履歴および成績データ
- アプリの設定情報

これらのデータはすべてお使いの端末（ローカルストレージ）内にのみ保存され、開発者や第三者のサーバーへ送信されることはありません。

### (2) URL取り込み機能における通信
ユーザーが指定したWebページのURLから問題文を抽出し自動成形する際、該当のWebサイトへアクセスしてコンテンツを取得します。この通信はコンテンツ取得のみを目的に使用されます。

### (3) AI補正機能における通信(任意、ユーザーが有効化した場合のみ)
設定画面でユーザー自身のGemini APIキーを登録すると、問題文の自動読み取りがうまくいかなかった場合に、確認ダイアログでユーザーが同意した上で、入力されたテキストをGoogle社のGemini API(ユーザー自身が取得・登録したAPIキーを使用)へ送信し、問題文・選択肢・正解の抽出をやり直す機能があります。この通信は、ユーザーが本機能を有効化し、都度の確認ダイアログで送信に同意した場合にのみ発生します。送信先は開発者のサーバーではなく、Google社が提供するAPIです。APIキー自体は端末内で暗号化して保管されます。

## 2. 第三者への提供

本アプリは、法令に基づく場合を除き、ユーザーの同意を得ることなく第三者に個人情報を提供することはありません。

## 3. アナリティクスおよび広告

本アプリは、広告表示のためにGoogle社が提供する「Google Mobile Ads SDK」を使用しています。このSDKは、広告の表示・最適化のために、端末の広告識別子(Advertising ID)や一般的な端末情報を処理する場合があります。これらの情報を収集・処理する主体はGoogle社であり、開発者自身がこれらの情報を収集・保存することはありません。広告配信に関する同意確認には、Google社が提供する「User Messaging Platform(UMP)」を使用しており、対象地域のユーザーには同意確認画面が表示されます。

広告を表示したくない場合は、アプリ内の「設定」画面から買い切り型の「広告を削除」機能(200円、Google Playの決済を通じて購入)をご利用いただけます。この購入処理はGoogle Playが行い、クレジットカード番号等の決済情報を開発者が取得・保存することはありません。

本アプリでは、上記の広告配信に伴うもの以外に、ユーザー追跡を目的としたサードパーティ製のアナリティクスツールは使用しておりません。

## 4. プライバシーポリシーの変更

本プライバシーポリシーは、アプリの機能追加や法令の変更に伴い、改定されることがあります。変更があった場合は、アプリ内または掲載ページにてお知らせいたします。

## 5. データの削除について

「過去問トレーナー」が端末内に保存するデータ（問題集データ、学習履歴、成績データ、設定情報）は、
すべてお使いの端末上にのみ存在し、開発者のサーバーには一切保存されていません。そのため、
削除のご依頼を開発者宛てに送っていただく必要はなく、以下の方法でユーザーご自身がいつでも
即座に削除できます。

- **個別の問題集を削除する場合**: アプリ内の「問題集一覧」画面で、削除したい問題集の
  「削除」ボタンをタップしてください。その問題集に紐づく設問・選択肢・学習履歴が
  即座に削除されます。
- **すべてのデータを削除する場合**: 端末の設定アプリから「過去問トレーナー」を
  アンインストールしてください。アプリのデータ（問題集・学習履歴・設定・保存済みAPIキー等）
  はすべて端末から完全に削除されます。

保持期間について、開発者側でのデータ保持は一切ありません（そもそも送信・保存されないため）。
端末内のデータは、上記いずれかの操作をユーザーが行うまで、ユーザー自身の端末にのみ保持されます。
