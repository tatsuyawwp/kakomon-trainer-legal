# プライバシーポリシー

**最終更新日: 2026年9月4日**

「過去問トレーナー」（以下、「本アプリ」）は、ユーザーの個人情報の保護を重視し、以下の方針に基づいて取り扱います。

## 1. 収集する情報とその利用目的

本アプリは、ユーザーのプライバシーを尊重し、個人を特定できる情報（氏名、メールアドレス、電話番号等）を収集・保持することはありません。

### (1) 端末内に保存されるデータ
- ユーザーが作成・取り込んだ問題集データ（設問、選択肢、解答）
- 学習履歴および成績データ
- アプリの設定情報

これらのデータはすべてお使いの端末（ローカルストレージ）内にのみ保存され、開発者や第三者のサーバーへ送信されることはありません。

### (2) URL取り込み機能における通信
ユーザーが指定したWebページのURLから問題文を抽出し自動成形する際、該当のWebサイトへアクセスしてコンテンツを取得します。この通信はコンテンツ取得のみを目的に使用されます。

### (3) AI補正機能における通信(任意、ユーザーが有効化した場合のみ)
設定画面でユーザー自身のGemini APIキーを登録すると、問題文の自動読み取りがうまくいかなかった場合に、確認ダイアログでユーザーが同意した上で、入力されたテキストをGoogle社のGemini API(ユーザー自身が取得・登録したAPIキーを使用)へ送信し、問題文・選択肢・正解の抽出をやり直す機能があります。この通信は、ユーザーが本機能を有効化し、都度の確認ダイアログで送信に同意した場合にのみ発生します。送信先は開発者のサーバーではなく、Google社が提供するAPIです。APIキー自体は端末内で暗号化して保管されます。

## 2. 第三者への提供

本アプリは、法令に基づく場合を除き、ユーザーの同意を得ることなく第三者に個人情報を提供することはありません。

## 3. アナリティクスおよび広告

本アプリでは、現在、ユーザー追跡を目的としたサードパーティ製のアナリティクスツールや広告配信サービスは使用しておりません。

## 4. プライバシーポリシーの変更

本プライバシーポリシーは、アプリの機能追加や法令の変更に伴い、改定されることがあります。変更があった場合は、アプリ内または掲載ページにてお知らせいたします。
